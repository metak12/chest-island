# Chest Island

Счётчик сундуков Fortnite для Windows с игровым оверлеем.

[Скачать установщик](https://github.com/metak12/chest-island/releases/latest/download/Chest-Island-Setup.exe)

1. Установи Chest Island и открой ярлык.
2. Включи распознавание и оверлей.
3. В Fortnite выбери русский интерфейс и режим «Окно на весь экран».
4. Для изменения позиции нажми «Переместить», перетащи сам счётчик и отпусти мышь.

Приложение распознаёт текст уведомлений об опыте. Отдельные подписи редких сундуков и сундуков с духом учитываются в своих категориях и в общем счёте. Если Fortnite показывает для редкого сундука или сундука с духом обычную подпись «СУНДУК», программа может засчитать его только в общий счёт. Поддержка новых подписей требует проверки в матче. Удары по опоре под сундуком в этой версии не отслеживаются.

Приложение проверяет GitHub Releases при запуске. Когда доступна новая версия, кнопка «Обновить» скачивает установщик и проверяет SHA-256 по данным GitHub. Установка начинается после подтверждения в установщике.

Для локальной сборки запусти `powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Build.ps1`. Установщик будет в `dist`. Приложение использует Windows OCR с русским языковым пакетом. Счёт и позиция хранятся в `%APPDATA%\FortniteChestCounter`.
