# Chest Island

<img src="assets/ChestIsland.svg" width="96" alt="Chest Island">

Счётчик сундуков Fortnite для Windows с игровым оверлеем.

[Скачать установщик](https://github.com/metak12/chest-island/releases/latest/download/Chest-Island-Setup.exe)

1. Установи Chest Island и открой ярлык.
2. Включи распознавание и оверлей.
3. В Fortnite выбери русский интерфейс и режим «Окно на весь экран».
4. Для изменения позиции нажми «Переместить», перетащи сам счётчик и отпусти мышь.

Любое уведомление об опыте со словом «СУНДУК» прибавляет один к общему счёту, в том числе «РЕДКИЙ СУНДУК» и «СУНДУК С ДУХОМ». Разрушение опоры без уведомления об опыте не засчитывается.

Chest Island проверяет GitHub Releases при открытии и перед включением распознавания или оверлея. Если доступна новая версия, «Обновить» скачивает и проверяет установщик, заменяет файлы установленной копии и перезапускает приложение. Если GitHub недоступен, можно продолжить использовать текущую версию.

Для локальной сборки запусти `powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Build.ps1`. Установщик будет в `dist`. Приложение использует Windows OCR с русским языковым пакетом. Счёт и позиция хранятся в `%APPDATA%\FortniteChestCounter`.

Подпись Authenticode доступна при сборке с параметрами "-SigningThumbprint <отпечаток> -SignToolPath <путь к SignTool>". Нужен доверенный сертификат подписи кода в хранилище текущего пользователя.

В «Настройках» можно включить запуск с Windows. Chest Island будет ждать Fortnite в трее, а при запуске игры включит распознавание и оверлей. Здесь же меняются размер, непрозрачность и данные оверлея, с предпросмотром перед сохранением.

Во вкладке «История → Сессии» видны длительность каждого захода в Fortnite, число сундуков и темп за час. Запись начинается с версии 1.1.6 и учитывает только время работы распознавания и его автоматические срабатывания.

«Диагностика» показывает последнее уведомление об опыте, дату и причину зачёта или пропуска. Вкладка «История → Прогресс» показывает график за семь дней, лучший заход и средний темп за неделю.
